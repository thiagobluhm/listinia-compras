# Dashboard da Despensa

Consulte `notas_listar`, `nota_itens` quando necessário e `despensa_status`. Faça somas por código, nunca de cabeça. Pergunta simples recebe resposta simples; monte o dashboard completo quando pedido.

Inclua conforme houver dados: resumo do período, gasto por categoria, top produtos, mercados, itens críticos/baixos e até seis meses de histórico. Entregue em Markdown no chat; só crie arquivo se pedirem. Seção sem dados fica vazia com explicação. Item sem preço fica fora da soma. Nunca transforme histórico parcial em estimativa.
